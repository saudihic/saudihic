# لا تفتح الكود — استخدم لوحة الإدارة فقط

## افتح
`admin.html`

## عدّل
- نصوص الهوم العربي
- البطاقة الجانبية في الهيرو
- نصوص البروفايل العربي
- الصور والشعارات

## بعد التعديل
اضغط: تحميل ملف المحتوى

سينزل ملف:
`site-content.json`

ضعه مكان الملف القديم هنا:
`content/site-content.json`

## الصور
ضع الصورة الجديدة داخل مجلد:
`images`

ثم اكتب مسارها في لوحة الإدارة مثل:
`/images/new-hero.jpg`

## ملاحظة مهمة
هذه نسخة آمنة للتعديل بدون برمجة.  
لا تعدل ملفات HTML أو CSS إلا إذا كنت مطور.


# تقرير المراجعة النهائية — HIC V3

## النتيجة

تمت مراجعة النسخة النهائية من ناحية:

1. حجم النصوص في كروت الموقع.
2. توازن العناوين والفقرات في البروفايل العربي.
3. انسجام البروفايل العربي مع الهوم العربي.
4. حجم شعار الهيدر.
5. حجم شعار الفوتر.
6. قابلية القراءة على الجوال.

## ما تم ضبطه

- ضبط أحجام نصوص الكروت حتى لا تكون صغيرة أو ضخمة.
- رفع قراءة النص العربي داخل الكروت عبر line-height مناسب.
- تثبيت أحجام عناوين البروفايل العربي لتقترب من الهوم بدون تضخيم مبالغ.
- تكبير الشعار في الهيدر بشكل محسوب.
- تكبير الشعار في الفوتر بشكل محسوب.
- إضافة قواعد Mobile حتى لا تنفجر الأحجام على الشاشات الصغيرة.

## ملف التعديلات

تم وضع قواعد المراجعة البصرية في:

`assets/hic-final-qa-polish.css`

كما تم حقنها داخل صفحات HTML مباشرة لضمان عملها.

## ملاحظة

لم يتم تغيير تقسيم التصميم أو الـ Layout.  
التعديل فقط على الأحجام، القراءة، والتناسق البصري.
