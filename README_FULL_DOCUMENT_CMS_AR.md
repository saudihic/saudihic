# HIC CMS — لوحة تعديل كامل المستند

## ماذا تغير في هذه النسخة؟

تم تحويل النصوص والصور داخل الصفحات إلى عناصر قابلة للتعديل من لوحة الأدمن.

الصفحات المغطاة:
- الهوم العربي
- البروفايل العربي
- الهوم الإنجليزي
- البروفايل الإنجليزي

## كيف تستخدمها؟

1. افتح:
`admin.html`

2. اضغط:
`استيراد ملف المحتوى`

3. اختر:
`content/site-content.json`

4. عدّل أي نص أو صورة.

5. اضغط:
`تحميل ملف المحتوى`

6. استبدل الملف القديم هنا:
`content/site-content.json`

## الصور

إذا تريد تغيير صورة:
1. ضع الصورة الجديدة داخل مجلد:
`images`

2. في الأدمن اكتب المسار:
`/images/name.jpg`

## ملاحظة مهمة

هذه النسخة لا تغيّر التصميم.  
هي فقط تجعل النصوص والصور قابلة للإدارة.

إذا أضفت سكشن جديد مستقبلاً داخل HTML، يحتاج ربط جديد.
أما النصوص والصور الموجودة حالياً فقد تم ربطها قدر الإمكان.
