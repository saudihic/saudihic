# طريقة تعديل موقع HIC بدون برمجة

## الملف الأهم

افتح:

`admin.html`

من المتصفح.

## ماذا تفعل اللوحة؟

- تعديل نصوص الهوم العربي.
- تعديل بطاقة الهيرو.
- تعديل نصوص البروفايل العربي.
- تعديل مسارات الصور.
- تصدير ملف محتوى باسم:

`site-content.json`

## أين أضع ملف المحتوى؟

ضع الملف داخل:

`content/site-content.json`

واستبدل القديم.

## أين أضع الصور؟

ضع الصور داخل مجلد:

`images`

ثم اكتب مسارها في اللوحة مثل:

`/images/hero-new.jpg`

## ملاحظة مهمة

هذه لوحة إدارة بسيطة تعمل بدون خادم.  
للحفظ التلقائي المباشر داخل الموقع مثل WordPress، تحتاج استضافة تدعم CMS أو Backend.



## تعديلات بصرية مؤكدة في هذه النسخة

1. تم رفع حجم نصوص البروفايل العربي لتكون أقرب لتنسيق الهوم العربي.
2. تم تكبير شعار البنر/الهيدر في جميع الصفحات بشكل محسوب.
3. تم تكبير شعار/عنصر العلامة في أسفل الصفحة.
4. ملف التعديلات البصرية موجود أيضاً هنا:

`assets/hic-visual-adjustments.css`
